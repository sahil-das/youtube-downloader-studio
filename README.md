# YouTube Downloader Studio

A Python desktop application for managing authorized media downloads.

## Planned features
- CustomTkinter desktop interface
- Video and audio download modes
- Queue and playlist support
- Progress reporting and cancellation
- SQLite download history
- Dark and light themes
- Windows executable packaging

## Requirements
- Python 3.11+
- FFmpeg and FFprobe for media processing

## Development status
Initial project scaffolding. Features are not implemented yet.

## Development
See `AGENTS.md` for project conventions.

## Responsible use
Use the application only for media you own, have permission to download,
or are otherwise legally authorized to save. It does not aim to bypass DRM
or access controls.
